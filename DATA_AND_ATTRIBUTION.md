# Data source and attribution

The MIT license in this repository covers the original project code. It does
not replace the terms of the source database.

The saved evaluation tables and figures were derived from the Sleep-EDF
Database Expanded, version 1.0.0. PhysioNet distributes those database files
under the Open Data Commons Attribution License v1.0. Raw EDF recordings are
not included here.

When reusing the derived results, keep the Sleep-EDF and PhysioNet attribution
and follow the source database terms:

- Sleep-EDF Database Expanded, version 1.0.0:
  https://physionet.org/content/sleep-edfx/1.0.0/
- Version DOI: https://doi.org/10.13026/C2X676
- Open Data Commons Attribution License v1.0:
  https://opendatacommons.org/licenses/by/1-0/

PhysioNet also asks users to cite the original Sleep-EDF publication and the
standard PhysioNet paper listed on the dataset page.

The automated labels were generated with YASA. The package and its associated
paper are linked from the project README.
